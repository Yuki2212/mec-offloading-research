# 分析コードの使い方

4冊のノートブックは条件・言語の設定と実行手順を持ち、描画・集計は `reporting.py` を共有します。
上から「設定 → CSV読込 → 指標の図 → ユーザ遅延 → 実行時間 → 集計表」の順に実行してください。
CSVは各1回だけ読み込み、作業ディレクトリは変更しません。

| ノートブック | 起動エネルギー | 言語 | 標準の図 | 集計表 |
|---|---:|---|---:|---:|
| `analyze01.ipynb` | 1.0 J | 日本語 | 12種類・PDF | 5種類 |
| `analyze02.ipynb` | 0.5 J | 日本語 | 11種類・PDF | 4種類 |
| `analyze03.ipynb` | 1.5 J | 日本語 | 11種類・PDF | 4種類 |
| `analyze01_English.ipynb` | 1.0 J | 英語 | 12種類・PDFとPNG | 5種類 |

元の出力範囲に合わせ、実行時間の図表は1.0 J条件で有効にしています。他条件でも `INCLUDE_RUNTIME = True` で出力できます。
出力先は `outputs/analysis/organized/<ノートブック名>/` です。以前の生成物と混ざらない新しい保存先です。

## 整理した内容

- CSVの再読込、同じ描画設定や関数の再定義を共通化。
- 0.5 J・1.5 J条件で2回出していた締切超過の箱ひげ図を1回に統一。
- 0.5 J条件で `result01/` に保存していたパスを解消。
- 起動MEC台数は標準では箱ひげ図のみ。バイオリン図は任意表示へ移動。
- 実行時間は標準では4手法の対数バイオリン図のみ。平均棒グラフ・2手法比較は任意表示へ移動。
- 空セル、Markdownに貼られていた未実行コード、重複した表生成関数を除去。
- 表の平均・母分散を1つの関数で計算し、CSVとLaTeXに保存。英語版の表見出しも英語に統一。
- 図の色・書式を統一。表のLaTeXは独自の `\bhline` を必要としない `\hline` 形式へ変更。

## 標準出力

連続値のバイオリン図8個：`energy`、`viol_rate`、`max_delay`、`avg_delay`、`avg_ue_energy`、`E_mec`、`E_cloud`、`jain_delay`。
これに起動台数の箱ひげ図、総遅延の棒グラフ、締切超過者だけの箱ひげ図が加わります。
実行時間を有効にすると `runtime_violin_log` を追加します。

表は `energy_mean`、`energy_var`、`qoe_mean`、`qoe_var`、必要に応じて `runtime_mean` を保存します。
集計は元と同じシナリオ単位の平均・母分散（`ddof=0`）。表の手法順はGA・CEGA・Greedy・Random、図はGA・Greedy・CEGA・Randomです。
図の総遅延はユーザ別CSVの全行の合計、締切超過図は `excess > 0` を抽出します。実行時間の対数図では0以下を除きます。

## 別表示を出す場合

設定セルの `SHOW_ALTERNATIVES = True` にします。
`num_active_mec_violin`、実行時間を有効にしている場合は `runtime_bar_log` と `runtime_violin_ga_vs_cega_linear` を追加します。
用途が違う図として保存名を分け、同じ図を複数回作るコードは持ちません。
任意図を一度作った後に設定をFalseへ戻しても、以前のファイルは削除しません。今回生成した図は `report.generated` で確認できます。

描画を表示せずファイルだけ作る場合は `AnalysisReport(..., show=False)` を使用します。
日本語フォント候補・ラベル・色は `reporting.py` で管理します。
図や表のセルを再実行すると同じ名前の生成物を更新します。元CSVは書き換えません。
